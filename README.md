# Διαχείριση Υπηρεσιών Ελληνικού Στρατού (Greek Army Shift Manager)

Αυτόνομη εφαρμογή επιφάνειας εργασίας (Desktop Application) για Windows, ειδικά σχεδιασμένη για χρήση σε στρατιωτικές μονάδες **χωρίς καμία απαίτηση σύνδεσης στο διαδίκτυο (100% Offline)**. Το εκτελέσιμο αρχείο μπορεί να μεταφερθεί και να εκτελεστεί απευθείας από ένα **USB Flash Drive**.

---

## 🎖️ Κύρια Χαρακτηριστικά

### 1. Μηδενική Εξάρτηση από Internet (Portable USB Executable)
- Πακεταρισμένη σε **ένα αυτόνομο εκτελέσιμο αρχείο**: `dist-portable/ShiftManager.exe` (~100 MB).
- **Χωρίς εγκατάσταση** και **χωρίς δικαιώματα διαχειριστή (Admin)**: Εκτελείται σε οποιοδήποτε PC με Windows 10/11.
- **Αποθήκευση Δεδομένων στο USB**: Τα δεδομένα αποθηκεύονται αυτόματα στο αρχείο `army_shifts_data.json` δίπλα στο `.exe` στο USB drive.

### 2. Δύναμη & Προσωπικό Μονάδας (Personnel Roster)
- Πλήρης ιεραρχία βαθμών του Ελληνικού Στρατού (Στρ, Υπδνεας, Δνεας, Λχιας, Επχιας, Αρχιας, Ανθστής, ΔΕΑ, Ανθλγός, Υπλγός, Λγός).
- Κατηγοριοποίηση: Αξιωματικοί, Υπαξιωματικοί, Κληρωτοί οπλίτες θητείας.
- Κατάσταση: Ένοπλος (Ι1, Ι2), Άοπλος (Ι3, Ι4), Υπηρεσία Γραφείου, Ελεύθερος Υπηρεσίας (Ε.Υ.).
- Όπλα, Ειδικότητες (Τουφεκιοφόρος, Οδηγός, Μάγειρας, Διαβιβαστής, κλπ) και Λόχοι.
- **Μετρητές Δικαιοσύνης (Μόρια Υπηρεσιών)**: Αυτόματη καταγραφή συνολικών υπηρεσιών και υπηρεσιών Σαββατοκύριακων/Αργιών για ισότιμη κατανομή ("αποφυγή χώσιμου/εμπλοκής").

### 3. Άδειες & Απαλλαγές (Leaves & Exemptions)
- Καταγραφή Κανονικών, Τιμητικών, Αναρρωτικών αδειών και Ελεύθερων Υπηρεσίας (Ε.Υ.).
- Γρήγορα κουμπιά διαρκειών (Ε.Υ. 24ωρο, 48ωρο, 3ήμερη, 5ήμερη, 10ήμερη).
- Αυτόματη εξαίρεση των απόντων από τη μηχανή υπηρεσιών.

### 4. Υπηρεσίες & Πόστα (Duty Types Configuration)
- Προκαθορισμένα βασικά πόστα Ελληνικού Στρατού:
  - **ΑΥΔΜ** (24ωρη - Αξιωματικός)
  - **ΒΑΥΔΜ** (24ωρη - Υπαξιωματικός)
  - **Επόπτης / Αρχιφύλακας** (24ωρη - Υπαξιωματικός)
  - **Σκοπός Κεντρικής Πύλης** (Βάρδιες - Ένοπλος)
  - **Περίπολος Στρατοπέδου** (Βραδινή βάρδια - Ένοπλος)
  - **Θαλαμοφύλακας** (Ημερήσια & Νυκτερινή - Ένοπλος/Άοπλος)
  - **Οδηγός Υπηρεσίας** (Ειδικότητα Οδηγού)
  - **Εστιάτορας / Μαγειρεία** (Άοπλος)
- Δυνατότητα προσθήκης νέων πόστων ανά μονάδα (π.χ. Αποθήκες Πυρομαχικών, Όπλα, Πύλη 2).

### 5. Ευφυής Μηχανή Παραγωγής Υπηρεσιών (Shift Engine)
- **Αυτόματη ανάθεση (Auto-Assign)** βάσει αλγορίθμου:
  - Εξαιρεί όσους βρίσκονται σε άδεια ή Ε.Υ.
  - Σεβασμός ανάπαυσης: Προτεραιότητα σε όσους **δεν υπηρέτησαν χθες** και έχουν ξεκουραστεί περισσότερες ημέρες.
  - Έλεγχος καταλληλότητας βαθμού (π.χ. ΑΥΔΜ μόνο Αξιωματικός).
  - Έλεγχος οπλισμού (π.χ. Σκοπιές μόνο Ένοπλοι).
  - Έλεγχος ειδικότητας (π.χ. Οδηγός Υπηρεσίας μόνο με ειδικότητα Οδηγού).
  - Ισότιμη κατανομή με βάση τα συνολικά μόρια και τα Σαββατοκύριακα.
- **Χειροκίνητη Παρέμβαση (Manual Override)** & Εργαλείο **Εναλλαγής (Swap)** με ένα κλικ.
- **Ανίχνευση Συγκρούσεων σε πραγματικό χρόνο**: Ένδειξη σφάλματος αν ανατεθεί στρατιώτης σε άδεια ή αν υπάρξει διπλή ανάθεση την ίδια ημέρα.

### 6. Επίσημη Εξαγωγή & Εκτύπωση (Excel & Print)
- **SheetJS (.xlsx)**: Εξαγωγή σε επίσημο στρατιωτικό υπόδειγμα Excel με κεφαλίδες ΕΛΛΗΝΙΚΗ ΔΗΜΟΚΡΑΤΙΑ / ΥΠΟΥΡΓΕΙΟ ΕΘΝΙΚΗΣ ΑΜΥΝΑΣ, πλήρη στοιχεία μονάδας και πλαίσια υπογραφών.
- **Εκτύπωση A4 (@media print)**: Έτοιμη διάταξη για άμεση εκτύπωση (Ctrl+P) με υπογραφή Διοικητή και Αξιωματικού Υπηρεσίας.

## 🛠️ Τεχνολογική Αρχιτεκτονική

- **Frontend**: [Angular 22](https://angular.dev/) (Standalone Components, Signals, Hash Routing).
- **Desktop Shell**: [Electron](https://www.electronjs.org/) με ασφαλή δίαυλο IPC (`contextBridge`).
- **Persistence**: Ατομική αποθήκευση JSON με δυνατότητα αντιγράφων ασφαλείας (Backups) και φορητότητας USB (`process.env.PORTABLE_EXECUTABLE_DIR`).
- **Excel Engine**: [SheetJS (xlsx)](https://sheetjs.com/) εκτελούμενο 100% τοπικά.
- **Packaging**: [Electron-Builder](https://www.electron.build/) στοχεύοντας αυτόνομο Windows Portable executable.

## 💻 Εντολές Ανάπτυξης & Μεταγλώττισης

### Προετοιμασία
```bash
npm install
```

### Εκκίνηση σε περιβάλλον Electron (Development)
```bash
npm run build
npm run electron
```

### Μεταγλώττιση Angular
```bash
npm run app:build
```

### Δημιουργία Αυτόνομου Portable Executable (.exe) για USB
```bash
npm run electron:build
```
Το αρχείο θα παραχθεί στη διαδρομή:
```
dist-portable/ShiftManager.exe
```

## 📦 Οδηγίες Αντιγραφής σε USB Flash Drive

1. Συνδέστε το USB Flash Drive στον υπολογιστή σας.
2. Αντιγράψτε το αρχείο `dist-portable/ShiftManager.exe` μέσα στο USB.
3. (Προαιρετικό) Μπορείτε να αντιγράψετε και το αρχείο `army_shifts_data.json` αν έχετε ήδη καταχωρημένα δεδομένα. Διαφορετικά, το πρόγραμμα θα δημιουργήσει αυτόματα το αρχείο στο USB κατά την πρώτη εκκίνηση.
4. Συνδέστε το USB σε οποιοδήποτε υπολογιστή της μονάδας και ανοίξτε το `ShiftManager.exe`.
